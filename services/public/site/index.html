    Systems that banks trust with their releases.

    Client names are left out on purpose. The numbers are from the projects themselves.

    Federal company · 90+ development teams · 200+ products · team of 3 engineers · 1 year

    Secure development process across the whole company

    Before

    Dozens of teams shipped code with no shared security checks, and open source packages reached developers unchecked.

    What I did

    • Deployed OSA Firewall and put it into the package supply chain, so open source dependencies are checked before developers get them.
    • Deployed an ASOC platform that collects findings from every scanner in one place.
    • Added Gitleaks, Trivy, SCA and OSA checks to the shared GitLab CI templates, so teams got them without writing pipelines by hand.
    • Trained DevOps engineers and developers to work with the findings. Together with the client we prepared and agreed 30+ process documents and instructions.

    Result

    100% of pipelines run security checks

    Press release about the project

    GitLab CIOSA FirewallASOCGitleaksTrivySCA

    Major bank · air-gapped network

    Signed package delivery into a closed network

    Before

    The bank's Nexus repository has no internet access, and every package that enters it has to come from a trusted source.

    What I did

    • Built a delivery service in Python that runs on Kubernetes.
    • Every package is signed with GPG, and the signature is checked before it lands in Nexus.

    Result

    Developers in the closed network get the packages they need, and each one can be traced to a signature.

    PythonKubernetesGPGNexus
